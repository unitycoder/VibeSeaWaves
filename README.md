# VibeSeaWaves

Fable AI generated 1 shot ocean shader.
If you want the same skybox, download from: https://polyhaven.com/a/citrus_orchard_puresky

### Setup
- Clone this repo
- Open project in Unity
- Drag Prefabs/OceanGenerator into scene
- Done!
